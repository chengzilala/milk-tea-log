      记录和照片只存在这台设备的浏览器里，不会上传到服务器。换手机、换浏览器、清除浏览器数据或系统自动清理后，就看不到了，需要自己导出备份再导入。装到桌面并经常打开，能少被系统当成「不用的网站」清理。

      添加到手机桌面

      装到桌面后，点图标就能直接打开，像一个小 App，不用每次翻浏览器。

      iPhone / iPad

      用 Safari 打开本页 → 点底部「分享」→ 选「添加到主屏幕」→ 右上角「添加」。

      安卓手机

      用 Chrome / Edge 打开本页 → 点右上角「⋮」→ 选「添加到主屏幕」或「安装应用」→ 确认。

      在微信里打开时没有这个入口：先点右上角「···」→「在浏览器打开」，再按上面的步骤操作。

      关于

      记录与照片只存在本机浏览器；识别时照片会上传到自有服务端并转发给模型，服务端不保存照片。
