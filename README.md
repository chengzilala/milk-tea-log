# milk-tea-log — 拍一杯（H5 验证版）

> 拍一张照，AI 自动认下饮品名，按城市/区存档成一枚印章，形成个人「奶茶印章地图」。
> 当前阶段：**H5 验证版**——先验证「有没有人愿意持续记」，不追求完整产品。
> **域名 / 备案 / 上线**：统一记在 [部署上线备案/README.md](../部署上线备案/README.md)（唯一台账），本文不重复。

## 这是什么

- 参考产品：**CapWords**（拍照识词，苹果设计大奖 2025）。学它的「低摩擦 + 即时回报」，不照抄贴纸皮肤。
- 目标用户：每周 ≥2 杯、会发朋友圈/小红书、想留下点记录的人。
- 核心闭环：**拍照 → AI 认饮品名 + 定位城市/区 → 生成印章 → 按月归档 → 地图**。
- 当前版本 v0.5.5：手机优先 H5 + Node 服务端；AI 识别（豆包 / 方舟，兼容通义千问 VL）、照片 EXIF 拍摄地 / 拍摄时间自动填充、逆地理编码（高德）、IndexedDB 本地存图、Leaflet 印章地图、记录字段扩展、导入导出、统计与徽章、4 套主题色、1080×1440 分享卡、服务端抠图贴纸（确认卡当场预览）+ 贴纸册 / 清单视图。

## 当前能做什么

- 拍照/从相册选一张奶茶图（本机压缩到 1280px，再上传识别）
- AI 自动识别饮品名（豆包 / 方舟，可换通义千问 VL）；识别失败可手动写，不阻塞保存
- 定位自动解析城市/区（高德逆地理）；非 HTTPS 或拒绝授权时可手填
- 生成印章，按月份归档到浏览器 IndexedDB（库 `mtl`，表 `records`）
- 点印章可编辑 / 删除；保存时可补品牌、价格、糖度、冰量、杯型、小料、评分（全选填）
- 最近常喝 3 选 1，自动记住你改过的饮品名（识别纠错）
- 导出 / 导入 JSON 备份（含图片 dataURL），同 ID 跳过，不重复导入
- 「我的」面板：本周 / 本月 / 今年杯数与花费、最爱品牌 / 饮品 TOP3、近 12 周热力图、连续打卡、6 枚徽章
- 4 套主题色：焦糖 / 抹茶 / 樱花 / 蓝莓
- Leaflet 印章地图：有坐标的印章以缩略图落在图上，约 100 米内多杯聚合为一个落点
- 详情页「做张分享卡」：本机 Canvas 生成 1080×1440 PNG（照片、品牌、品名、规格、糖度点阵、累计/本月杯数、花费、评分），可保存或调用系统分享
- 归档支持三种视图：印章 / 贴纸册（3 列深色卡）/ 清单，选择会记住
- 服务端抠图 `/api/cutout`（remove.bg 代理）+ 本机白边处理：拍照时后台自动生成贴纸；没配 Key 或失败时自动降级为原图贴纸卡；详情页可手动「生成贴纸 / 重做贴纸」
- 详情页可改日期，支持跨月补记（保存后自动跳到对应月份）

## 部署方案（测试用）

| 方案 | 组成 | 能测 AI/定位 | 适合 |
|---|---|---|---|
| **腾讯云轻量整站（本次采用）** | 一台机器跑页面 + 4 个接口，Caddy 自动 HTTPS | 能 | 多人多天测试（地址固定） |
| 临时隧道 | Mac `npm start` + cloudflared | 能 | 自己真机调试（地址会变） |
| 帽子云 + 云主机 | 静态页走 CDN，`/api*` 反代到云主机 | 能 | 后期访问量变大再加 |
| 只上帽子云 | 仅静态托管 | **不能**（帽子云不跑 Node，Key 也不能进前端） | 只能看界面 |

> 采用「腾讯云轻量整站」：已上线 **https://mtl.chesterlee.cn**（腾讯云轻量 · Caddy 自动 HTTPS）；域名 / 备案 / 部署位置以 [部署上线备案](../部署上线备案/README.md) 为准。
> 一个 Node 进程同时托管页面和接口。完整步骤见 [usage/Running.md 第 9 节](usage/Running.md)。
