# milk-tea-log — 拍一杯（H5 验证版）

> 拍一张照，AI 自动认下饮品名，按城市/区存档成一枚印章，形成个人「奶茶印章地图」。
> 当前阶段：**H5 验证版**——先验证「有没有人愿意持续记」，不追求完整产品。
> **域名 / 备案 / 上线**：统一记在 [部署上线备案/README.md](../部署上线备案/README.md)（唯一台账），本文不重复。

## 这是什么

- 参考产品：**CapWords**（拍照识词，苹果设计大奖 2025）。学它的「低摩擦 + 即时回报」，不照抄贴纸皮肤。
- 目标用户：每周 ≥2 杯、会发朋友圈/小红书、想留下点记录的人。
- 核心闭环：**拍照 → AI 认饮品名 + 定位城市/区 → 生成印章 → 按月归档 → 地图**。
- 当前版本 v0.21.6：手机优先 H5 + Node 服务端；AI 识别（豆包 / 方舟，兼容通义千问 VL）、照片 EXIF 拍摄地 / 拍摄时间自动填充、逆地理编码（高德）、城市改成弹层点选（可上下滑动挑 + 搜索 + 一键用当前位置自动填）、IndexedDB 本地存图、高德 JS API 地图（自有 GeoHUB 自定义底图样式；全国全貌 → 点城市 → 城市内看喝过的每一杯）、记录字段扩展、导入导出、统计、4 套风格主题（纸感贴纸 / 暖棕展台 / 彩色卡片 / 极简留白）、1080×1440 分享卡、服务端抠图贴纸（确认卡当场预览）+ 贴纸册 / 清单视图、真机测试诊断日志、价格一键点选（历史价 → 品牌价带 → 通用价点，估算价标「约」）、这一杯的心情（6 个手绘卡通表情直接点选，选填）、语音备注（点一下说 ≤60 秒，语音随记录存本机；能转文字时优先走服务端转写、未配置则用手机浏览器边说边转，都不行就只留语音）、品牌识别与品牌墙（AI 顺带猜品牌、30 个主流品牌字典 + 品牌色徽章、「我的」页品牌墙标出每个品牌喝了几杯）、饮品名搜索与候选（内置 30 个品牌的常见单品菜单库：AI 认出名字先对齐成标准写法，只认出品牌就给该品牌常见款点选，同名同糖冰杯型点过 ≥2 次会出现「老样子」；「搜饮品名」可跨品牌搜，手填的新名字按品牌记在本机）、口味档案（「我的」页按已有记录自动算出常点品牌 / 饮品 / 糖度 / 冰量 / 均价 / 常喝时段 / 最常心情，并轻提示「打过高分但 7 天没点」的饮品，不用额外填）、可选登录统一账户（「我的」页顶部入口：一处登录、各作品通用；账户中心只提供身份，拍一杯的记录 / 照片 / 语音仍只存本机，不传任何业务数据）；首页极简：首屏只有问候 + 一枚大快门按钮（落在拇指区，外围一大片同色雾光慢慢一呼一吸），v0.21.3 起快门下方补一块「最近一杯」小卡（缩略图 + 名字 + 品牌 · 今天 / 昨天，点开看详情）和一行「本周 N 杯 · 最常 X」，没有记录时都不显示，点快门进自有全屏相机；底部导航收缩为图标悬浮胶囊（拍一杯 / 印章 / 地图 / 我的，无文字，「我的」是普通页面不是弹层）；首次打开弹一次「把拍一杯放到桌面」提示（记住后不再弹，从桌面图标打开时也不会弹）；自带手绘奶茶杯主屏图标（Web App Manifest + apple-touch-icon）。

## 怎么跑

```bash
cd /Users/Admin/Knowledge/Coding/milk-tea-log
npm install
cp .env.example .env   # 填入 DASHSCOPE_API_KEY、AMAP_KEY，以及地图用的 AMAP_JS_KEY / AMAP_JS_SECURITY
npm start
```

然后打开：http://localhost:8830

> iPhone 真机测试需要 HTTPS：另开终端执行
> `~/.local/bin/cloudflared tunnel --url http://localhost:8830`，
> 用打印出的 `https://xxx.trycloudflare.com` 在 Safari 打开。
> 详细步骤见 [usage/Running.md](usage/Running.md)。
>
> 官网介绍页（`site/`）单独预览：`python3 -m http.server 8899 -d site`，打开 http://localhost:8899 ，该文件夹可直接整包上传。

## 当前能做什么

- 拍照/从相册选一张奶茶图（本机压缩到 1280px，再上传识别）
- AI 自动识别饮品名（豆包 / 方舟，可换通义千问 VL）；识别失败可手动写，不阻塞保存
- 定位自动解析城市/区（高德逆地理）；非 HTTPS 或拒绝授权时可手填
- 生成印章，按月份归档到浏览器 IndexedDB（库 `mtl`，表 `records`）
- 点印章可编辑 / 删除；保存时可补品牌、价格、糖度、冰量、杯型、小料、评分（全选填）
- 最近常喝 3 选 1，自动记住你改过的饮品名（识别纠错）
- 导出 / 导入 JSON 备份（含图片 dataURL），同 ID 跳过，不重复导入
- 「我的」面板：本周 / 本月 / 今年杯数与花费、最爱品牌 / 饮品 TOP3、近 12 周热力图、连续打卡
- 4 套风格主题：纸感贴纸（默认）/ 暖棕展台 / 彩色卡片 / 极简留白，在「我的 → 主题风格」切换并记住
- 高德 JS API 地图 + **GeoHUB 自定义底图样式**（奶油陆地 / 浅蓝水系 / 近白路网，注记与楼块全关、省界线隐藏；canvas 再 `saturate(0.4)` 压饱和）：两级视角——缩放 < 9 只显示**城市数字徽章**（一眼是「我去过几座城市、各喝了几杯」），点徽章下钻到该城市并弹出底部卡片，列出这城喝过哪几杯；放大到 ≥ 9 自动换成**地点小图钉**，点开看单杯详情；顶部一行小字统计，点地图空白处收起卡片
- 详情页「做张分享卡」：本机 Canvas 生成 1080×1440 PNG（照片、品牌、品名、规格、糖度点阵、累计/本月杯数、花费、评分），可保存或调用系统分享
- 归档支持三种视图：印章 / 贴纸册（3 列深色卡）/ 清单，选择会记住
- 服务端抠图 `/api/cutout`（remove.bg 代理）+ 本机白边处理：拍照时后台自动生成贴纸；没配 Key 或失败时自动降级为原图贴纸卡；详情页可手动「生成贴纸 / 重做贴纸」
- 详情页可改日期，支持跨月补记（保存后自动跳到对应月份）
- 真机测试诊断日志：前端把选图 / EXIF / 压缩 / 识别 / 定位 / 抠图 / 保存的结果上报 `/api/log`，服务端按天落盘到 `logs/client-*.jsonl` 与 `logs/server-*.jsonl`；只记流程和结果，不含图片与 Key
- 可选登录统一账户（v0.21.2）：「我的」页顶部一枚账户入口——未登录点一下去账户中心登录、登完带一次性票据跳回本页；已登录点一下进账户中心。账户中心只提供身份（uid），拍一杯的记录 / 照片 / 语音不传、不搬；页面加载不触发静默跳转，账户服务不可用时入口退回普通「去登录」链接，记录功能照常

## 部署方案（测试用）

| 方案 | 组成 | 能测 AI/定位 | 适合 |
|---|---|---|---|
| **腾讯云轻量整站（本次采用）** | 一台机器跑页面 + 4 个接口，Caddy 自动 HTTPS | 能 | 多人多天测试（地址固定） |
| 临时隧道 | Mac `npm start` + cloudflared | 能 | 自己真机调试（地址会变） |
| 静态 CDN + 云主机 | 静态页走 CDN，`/api*` 反代到云主机 | 能 | 后期访问量变大再加 |

> 采用「腾讯云轻量整站」：已上线 **https://mtl.chesterlee.cn**（腾讯云轻量 · Caddy 自动 HTTPS）；域名 / 备案 / 部署位置以 [部署上线备案](../部署上线备案/README.md) 为准。
> 一个 Node 进程同时托管页面和接口。完整步骤见 [usage/Running.md 第 9 节](usage/Running.md)。
